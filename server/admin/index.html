Export cookies.txt safely

  1. Open a private window (incognito) in your browser on a computer.
  2. Sign in to youtube.com (or music.youtube.com: same cookies) in that window.
  3. Export the cookies with a cookies.txt browser extension while that page is open, then upload the file here.
  4. Close the private window at once. If a browser keeps using that session, Google signs it out and the server loses access.
Use a separate Google account for the server, not your main one. Anyone with this file can use that account.

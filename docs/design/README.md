# Screen mockups

Five artboards at the Y1's 480×360. Each is a self-contained HTML file; the inline styles carry the exact sizes (row heights, thumbnail sizes, colors, type sizes) to build from.

| File | Screen | Notes |
| --- | --- | --- |
| Main.dc.html | Main menu, iPod-style shell | light `#f4f4f2`, 36 px rows, 240 px list + art pane, 30 px status bar |
| MusicHome.dc.html | YouTube Music home | dark `#0f0f0f`, Roboto, 46 px rows with 36 px art, uppercase section headers, 30 px mini-player bar |
| NowPlaying.dc.html | Now playing (music) | 184 px art, 21 px title, progress bar with 12 px thumb |
| VideoHome.dc.html | YouTube home | pill tabs, 80 px rows, 112×63 thumbs with duration badge and watched bar |
| VideoPlayer.dc.html | Video player with quality menu open | 16:9 letterboxed at 480×270, 56 px top / 58 px bottom overlays, 168 px quality panel |

Update Rondo

Bring the Rondo on your Innioasis Y1 up to date from this page, over USB. It takes a minute, keeps your settings, Wi-Fi, playlists and music, and needs nothing installed on your computer.

This browser can't talk to USB devices. Open this page in Chrome or Edge on a computer, or in Chrome on an Android phone with a USB-C cable. Or update over Wi-Fi from the Y1 itself (Settings › System › Software update) or from its dashboard.
This is for a Y1 that already runs the Rondo firmware. To install Rondo for the first time, or to move from Rondo 1.0 to 2.0, use Innioasis Updater CE.

The Y1 doesn't show up, or connecting fails
  • Try another cable. Many USB-C cables only charge.
  • Only one program can use the Y1's USB connection at a time. Close the Innioasis Updater, and if you've used adb, run adb kill-server. Then unplug the Y1, plug it back in and try again.
  • Windows: the Y1 needs Google's USB driver (it shows up as "Android ADB Interface" in Device Manager).
  • Linux: your user needs access to the device. A udev rule for USB ID 0bb4:0c03, or the plugdev group, does it.
  • With adb, the same update takes three commands; Building Rondo has them.
